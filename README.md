# Password Manager — Android Application (Mini Project)

[![Author](https://img.shields.io/badge/Author-keshav647-0EA5E9?style=for-the-badge&logo=github)](https://github.com/keshav647)

Android Password Manager application built with Java, Material Design components, customizable password generation parameters, local encrypted credential storage, and AWS Amplify integration.

## Features
- **Custom Password Generator**: Configurable length and character sets (uppercase, lowercase, digits, special symbols) with animated generation feedback.
- **Saved Passwords Vault**: View, copy, and manage stored account credentials.
- **Material UI**: Clean Android XML layouts with custom dialogs and toast feedback.
